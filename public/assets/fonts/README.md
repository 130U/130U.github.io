# Typography Assets

The interface intentionally uses one self-hosted variable-font family:

- **Shantell Sans** carries the complete visible type system. Neutral axis
  settings preserve long-form and academic readability, while controlled
  Informality and Bounce values distinguish display, interface, and personal
  brand roles. The Theodore Ouyang wordmark is upright and gains identity from
  weight, spacing, and the Informality axis rather than synthetic italics.

The particle word sampler remains on a platform geometric sans stack. This
keeps `THEODORE` and `OUYANG` deterministic and prevents font loading from
changing their point targets.
