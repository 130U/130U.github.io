# Personal Posts

The Personal Posts index is:

```text
app/personal-posts/page.tsx
```

Each article lives in a directory named after its public URL slug and uses the
router-required `page.tsx` filename.

Current article:

```text
app/personal-posts/from-vision-and-instructions-to-robot-actions/page.tsx
```

Post media belongs in:

```text
public/assets/posts/
```

Before adding a post, read:

```text
website-maintenance/03-adding-personal-posts.md
```
