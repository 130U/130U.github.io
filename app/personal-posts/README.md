# Personal Posts

The index renders the typed registry in:

```text
app/lib/content/posts.ts
```

Every public post URL is generated by:

```text
app/personal-posts/[slug]/page.tsx
```

Bespoke article bodies live under `app/personal-posts/_articles/`. The current
article is `RobotActionPathsPost.tsx`. Post media belongs in
`public/assets/posts/`; retain source files and add optimized derivatives
alongside them.

Before adding a post, follow
`website-maintenance/03-adding-personal-posts.md`.
